## Typography
- Define discrete mobile, tablet, and desktop type scales in global CSS and use semantic Tailwind text utilities, so every page shares readable hierarchy without viewport-scaled fonts.
- Keep editable fields at least 16px on mobile to prevent iOS focus zoom while allowing surrounding labels and headings to remain compact.
